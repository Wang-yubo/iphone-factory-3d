你是一名资深 Three.js / React Three Fiber 工程师兼游戏设计师。请为我从零构建一个可运行的 3D 网页项目：
「苹果手机生产线模拟器」。

【核心体验】
玩家是工厂产线工程师。开局所有工站料仓为空，玩家必须手动把 7 种原料
（铝锭、主板基板、SoC 芯片、玻璃面板、电池、摄像头模组、包装盒）投入对应工站的料仓，
然后按下「启动产线」。产线上每一台半成品都是真实 3D 物体，沿传送带依次经过 7 个工站：

1 冲压成型（铝锭→机壳，2.5s）
2 主板贴装（主板基板+芯片→主板总成，3.0s）
3 屏幕贴合（玻璃面板+机壳→屏装机壳，3.0s）
4 电池装配（电池+屏装机壳→电池总成，2.0s）
5 相机装配（3×摄像头模组+电池总成→半成品，2.5s）
6 功能检测（半成品→良品/不良品，4.0s，良率 92%）
7 包装（良品+包装盒→成品手机，2.0s）

每个工站有独立料仓（容量 12）和入口缓存（容量 3）；缺料则该工站红灯停线并弹出提示，
补料后自动恢复；缓存满则上游阻塞。成品手机计数 +1 并落到出货区货架上。

【必须实现】
- 全 3D 场景：车间地面、7 个工站、传送带、机械臂、料仓、出货货架、悬挂灯带
- 手动投料：从右侧原料仓库面板点击/拖拽原料到场景中的料仓，有抛物线落料动画和音效；
  也支持「批量补料 +5」「按 BOM 一键配齐」
- 传送带真实运转，零件沿带移动，机械臂抓取到加工台、做加工动画、再放回
- 检测站良率判定：不良品变红、被推入回收箱，不计数
- HUD：原料库存、各站料仓储量、在制品数、成品数、良率、UPH（每小时产能）
- 控制：启动/暂停、1x/2x/4x 变速、重置、相机预设（全景/俯视/跟随单台手机/工站特写）
- 缺料、堵料、停线都要有明确的视觉 + 文字提示
- 订单面板：同时 1 条进行中 + 2 条排队，按交付台数结算并自动接下一单

【技术约束】
- Vite + React + TypeScript + three + @react-three/fiber + @react-three/drei + zustand
- 所有几何体程序化生成（BoxGeometry/CylinderGeometry/LatheGeometry 等），禁止依赖任何外部
  模型文件、贴图、CDN 资源，保证 clone 下来就能跑
- 逻辑与渲染分离：产线状态机放在 zustand store 里，用固定时间步推进；3D 只做插值渲染
- 60fps 为目标，桌面 Chrome 为基准，窗口宽度 1280 以上
- TypeScript 严格模式无报错，`pnpm build` 通过，控制台无错误

【美术方向】
干净的工业极简风：深灰地面、白色铝合金产线、银灰机壳、苹果式留白，
点缀青蓝色科技光与琥珀色警示灯；柔和面光 + 轻微 Bloom，不要赛博朋克霓虹堆砌。

分阶段交付，每个阶段结束我都能 `pnpm dev` 打开看到可运行的结果：
P1 场景与相机 → P2 传送带与物料流动 → P3 原料系统与投料交互 → P4 工站加工与良率
